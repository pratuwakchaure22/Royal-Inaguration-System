# Code of Conduct

We are committed to a welcoming, harassment-free experience for everyone.

**Expected behaviour:** be respectful, give and accept constructive feedback gracefully, and focus on what is best for the community.

**Unacceptable behaviour:** harassment, insults, discriminatory language, personal attacks, or publishing others' private information.

Maintainers may remove, edit or reject contributions that violate this code. Report concerns by opening a private security advisory or contacting the repository owner.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
